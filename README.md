# Prediksi Indeks Pembangunan Manusia (IPM) di Jawa Tengah Tahun 2024 dengan Random Forest

## Deskripsi Project
Indeks Pembangunan Manusia (IPM) merupakan indikator yang digunakan untuk mengukur kualitas pembangunan manusia berdasarkan aspek kesehatan, pendidikan, dan standar hidup layak. Nilai IPM dipengaruhi oleh beberapa indikator utama, yaitu Usia Harapan Hidup (UHH), Harapan Lama Sekolah (HLS), Rata-rata Lama Sekolah (RLS), dan Pengeluaran Per Kapita yang Disesuaikan.

Dengan memanfaatkan teknik machine learning, khususnya algoritma Random Forest, dapat dilakukan klasifikasi kategori IPM suatu kabupaten/kota berdasarkan indikator-indikator tersebut.

## Tujuan
Membangun model Random Forest untuk memprediksi kategori IPM kabupaten/kota di Jawa Tengah berdasarkan data kesehatan, pendidikan, dan pengeluaran masyarakat.
